BEHIND THE CURTAIN

A genuine multilayer neural network

Each training step uses examples, calculates a prediction, measures error, and updates the weights using backpropagation and Adam optimization.

01 / INPUT

Coordinates

Two numbers, x and y, represent each point on the map.

02 / HIDDEN LAYERS

24 neurons

Two layers of 12 tanh neurons learn nonlinear relationships between points.

03 / OUTPUT

Probability

A sigmoid neuron predicts the probability that the point belongs to Class A.

04 / FEEDBACK

Backpropagation

Cross-entropy loss supplies feedback that updates weights after every mini-batch.
